# Purrfect

Welcome to **PURRFECT**, an educational programming compiler simulation designed to help students learn and understand the core phases of compiler design: lexical, syntax, and semantic analysis.

## About the Project

PURRFECT is a learning tool created to help students understand lexical, syntax, and semantic analysis through an interactive compiler simulation. This compiler evaluates the lexical, syntax, and semantic phases of programs written in Java.

### Core Phases Evaluated:
1. **Lexical Analysis:** Scans and breaks down source code into identifiable tokens.
2. **Syntax Analysis:** Examines structural relationships and parses expressions based on predefined language rules.
3. **Semantic Analysis:** Ensures code meaning and type correctness within the specified scope.

---

## Supported Tokens

The simulation identifies valid structural and syntax markers. Examples of valid tokens include:

* **Data Types:** `String`, `int`, `float`, `double`, `char`, `boolean`
* **Operators & Delimiters:** `=`, `;`

## Getting Started

Since **Purrfect** is a static frontend web application (built purely with HTML, CSS, and JS), it requires no installation of servers, node modules, or external databases.

### Clone the Repository

To download a copy of this repository onto your local computer, open your terminal or command prompt and run the following command:

```bash
git clone https://github.com/BaiSakinaAbad/Purrfect.git
```

### Open the Application

1. Navigate to the folder where you downloaded the project (e.g., `Purrfect`).
2. Look for the `index.html` file.  
3. Right-click `index.html` and select **"Open with..."**.
4. Choose your web browser (e.g., Google Chrome, Mozilla Firefox, Microsoft Edge).

---

## How to Use the Compiler

1. **Navigate** to the **Compiler** tab.
2. **Input** a line of code following the basic Java variable declaration syntax. Or download the txt_files to see examples.
3. **Click** "Analyze Code" to view the results of the lexical, syntax, and semantic analyses.
