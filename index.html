WELCOME TO PURRFECT

Your educational programming compiler for learning lexical, syntax and semantic analysis.

PURRFECT is a learning tool created to help students understand lexical, syntax, and semantic analysis through an interactive compiler simulation.

This compiler will evaluate the lexical, syntax, and semantic phases of programs written in Java.

"int"
"float"
"double"
"char"
